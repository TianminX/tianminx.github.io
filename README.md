# tianminx.github.io

Source for my academic website, [tianminx.github.io](https://tianminx.github.io).

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT license). Pushing to `main` builds the site with GitHub Actions and publishes it to the `gh-pages` branch.
